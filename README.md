# CalculaDI API

API pública e gratuita de índices financeiros brasileiros (IPCA, IGP-M, Selic, CDI acumulados) e calculadora de rendimento de CDB.

## Stack

- Node.js + TypeScript
- Fonte oficial de dados: Banco Central do Brasil (API SGS)
- Deploy serverless (Cloudflare Workers / Vercel)
